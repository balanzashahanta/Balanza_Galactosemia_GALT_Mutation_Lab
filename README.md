## Project Overview

This individual project investigates how a documented mutation in the GALT gene affects the predicted protein sequence. The documented GALT c.563A>G (p.Gln188Arg) variant was reproduced using Galaxy. A separate artificial synonymous mutation was also created and analyzed to compare different effects of sequence changes.
